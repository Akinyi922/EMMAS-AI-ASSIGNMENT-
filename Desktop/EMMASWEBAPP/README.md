# AURA Elegance

Premium luxury fashion and accessories storefront — a React + Vite single-page application.

## Stack

- **React 19** with Vite
- **Tailwind CSS v4**
- **Lucide React** icons
- **React Context** for cart, favorites, and filters

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
